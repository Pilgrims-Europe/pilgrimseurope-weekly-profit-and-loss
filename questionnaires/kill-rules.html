Poultry rejects

1Do part rejects reduce kill?

Some condemnation codes remove only part of a bird. An example is Croppings. The rest of the bird stays on the line.

Why this matters: in the last 8 weeks, Croppings was 3.8 million head at the pilot sites. That is about 10% of birds delivered. If it counts, kill is about 10% lower.

2Which condemnation codes are rejects?

The table shows each Mtech condemnation code that was used at the pilot sites in the last 8 weeks. Tick each code that is a reject. Leave the box empty if the code is not a reject.

Why this matters: kill uses the sum of the ticked codes. The sum of all codes is too high, because some codes are part rejects.

Period: 2026-09-14 to 2026-11-08. Values are head (number of birds). Birds delivered in this period: Anwick 16,272,819. Ashbourne 5,240,400. Dungannon 17,007,432.

3What do category 1 and category 2 mean?

Mtech gives each condemnation code a category: 1 or 2. Mtech does not say what they mean. Category 1 codes look like bird health conditions, for example Cellulitis. Category 2 codes look like factory damage, for example Machine Damage.

Why this matters: if one category is the rejects, the kill table can use the category. Then new codes go in the correct group.

Pork kill

4Which value is kill for a pork site?

The glossary defines kill for poultry only. Hellenic has a "Killed Qty" field for each booking. It also has pigs delivered, dead on arrival, dead in pen and casualty. A separate table has whole pigs condemned.

Why this matters: the two methods give different numbers. Since 2025-01-01, Westerleigh had 1,809,392 pigs delivered and a Killed Qty of 1,804,400. Spalding had 2,333,923 delivered and 2,333,613 killed.

Birds delivered

5Which head count is birds delivered: farm or plant?

Mtech has two head counts for each load. One is the farm head count. The other is the plant head count. Since 2019, the two counts are the same at all three pilot sites. They were different at Dungannon in 2018 only.

Why this matters: the risk is low now. But we must use the correct count if the two counts are different again.
