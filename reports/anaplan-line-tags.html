Rules

Source type

  • System: the value comes from one source system.
  • Calculation: a rule makes the value from system data.
  • Manual: site finance or another team enters the value.
  • Subtotal: a formula on other template lines. A subtotal has no RAG.

RAG

  • Green The data is in a PROD Snowflake schema and the rule is known.
  • Amber The data is in Snowflake, but the rule or mapping is Unknown. Or the data is only in a silver table, or only by period.
  • Red The value is manual, or the source is not in Snowflake, or the source is not researched.

The RAG is for the pilot sites, Redruth and Bromborough. The pilot sites do not kill. So the kill lines use the kill sites: Anwick, Ashbourne and Dungannon for poultry, and Spalding for pork.
